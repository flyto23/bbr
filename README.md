**XanMod 内核 + BBR v3 + VPS 网络调优**

一键安装 XanMod 内核，启用 BBR v3 拥塞控制，并提供内核/网络/反向代理/脚本维护等 12 项功能，专注把 VPS 的 TCP 吞吐和稳定性调好。

## 一键安装

**如果是新机器（未安装 curl），请先手动执行：**

```bash
apt update -y && apt install curl -y
```

**安装脚本（安装后只需输入 `bbr` 即可运行）：**

```bash
# 安装：下载脚本到 /usr/local/bin 并写入 bbr 快捷命令
bash <(curl -q -fsSL "https://raw.githubusercontent.com/flyto23/bbr/main/install-alias.sh?$(date +%s)")

# 重新加载配置
source ~/.bashrc  # 或 source ~/.zshrc

# 以后直接使用
bbr
```

**说明**：

- 脚本会下载到 `/usr/local/bin/net-tcp-tune.sh`，`bbr` 直接运行本地副本（启动快、不依赖网络）
- 下载或校验失败时自动退回“在线模式”（每次运行从 GitHub 拉取）
- 后续更新：运行 `bbr` → 选择 **98. 更新脚本**

## 最佳实践流程（作者推荐）

这是经过多次实测总结出的**推荐**优化路径，建议按顺序执行：

> **懒人方案**：直接执行 **功能 66**（一键全自动优化），脚本会自动完成以下所有步骤。

### 第一步：安装内核

- 执行 **功能 1**：安装 XanMod 内核 + BBR v3
- **注意**：安装完成后**必须重启 VPS** 才能生效

### 第二步：BBR 调优（核心步骤）

- 执行 **功能 3**：BBR 直连/落地优化
- **如何选择**：
  - **小白用户**：选择 `1` (自动检测)，脚本会跑一次 Speedtest 并自动计算最佳参数
  - **进阶用户（推荐）**：如果你清楚自己的线路带宽，直接手动选择档位（如 `500Mbps` 或 `1Gbps`）
  - _作者经验：我自己一般手动选 500M 或 700M 档位，效果最稳_
- **地区选择**：带宽检测后会询问服务器主要服务的地区
  - **亚太地区**（港/日/新/韩）：标准缓冲区，适合大多数用户
  - **美国/欧洲**（跨太平洋/大西洋）：大缓冲区，解决高延迟路径的吞吐量瓶颈

### 第三步：DNS 净化（可选，慎用）

- 执行 **功能 5**：NS 论坛-DNS 净化
- **两种模式**：
  - `1. 纯国外模式`：Google + Cloudflare，强制 DoT 加密（**抗污染推荐**）
  - `2. 纯国内模式`：阿里云 + 腾讯 DNSPod，无加密（国内DNS不支持DoT）
- **安全说明**：已内置完整的事务性回滚机制（执行前全量快照 → 任意步骤失败自动恢复原始状态），重启持久化也已修复。如仍有顾虑，建议在有 VNC/控制台的情况下首次使用。

## 核心特性详解

### 1. BBR v3 + 智能带宽优化 (功能 3)

基于 Google BBR v3 算法，配合脚本独家的**智能带宽检测**：

- 自动运行 Speedtest 测速
- 根据上传带宽自动计算最佳 TCP 窗口大小 (BDP)
- **地区选择**：支持亚太（RTT < 100ms）和美欧（RTT 150-300ms）两种模式，根据实际延迟自动计算最优缓冲区
- 动态调整 `rmem` 和 `wmem` 缓冲区，避免小内存机器 OOM，同时跑满大带宽机器性能
- 缓冲区按内存自动封顶并设置 `tcp_mem`；长距离线路连接起步更快（实测前 3 秒提速约 60%）
- 本内核不支持的参数自动跳过；多队列网卡逐队列启用 fq；已有端口限速或 CAKE 时不覆盖

### 2. 一键反代 (功能 9)

基于 Cloudflare Tunnel 的内网穿透，无需开放 VPS 80/443 端口，自动 HTTPS：

- **一键安装**: 自动按架构(amd64/arm64/arm/386)下载 cloudflared + 引导 OAuth 授权
- **快速部署**: 输入本地端口 + 域名即可完成隧道创建、DNS 路由、systemd 服务注册
- **失败自动回滚**: 任一步骤失败自动清理已创建的隧道 / DNS / systemd，不留孤儿
- **查看/删除**: 列出已部署的反代，支持停止服务、删除 unit 与配置文件，可选同时删除云端隧道

**典型使用场景**:

- VPS 没有公网 IP、被墙 443/80、想隐藏服务器真实 IP
- 自建服务通过自己的域名访问（NAS 面板 / 内网管理界面）
- 不想花钱买 SSL 证书，让 Cloudflare 统一托管 HTTPS

### 3. 一键全自动优化 (功能 66)

检测到未运行 XanMod 时先安装内核；重启后再次执行 66，会依次完成：

1. BBR 直连优化（自动检测带宽）
2. DNS 净化（纯国外模式）
3. Realm 转发修复
4. 禁用 IPv6（可选；纯 IPv6 机器会自动跳过，避免断 SSH）

### 4. 在线更新 (功能 98)

- 从 `https://github.com/flyto23/bbr` 的 `main` 分支拉取最新 `net-tcp-tune.sh`
- 下载后依次校验：非 HTML/错误页、shebang、脚本标记、`bash -n` 语法
- 校验通过才替换 `/usr/local/bin/net-tcp-tune.sh`，旧版本自动备份为 `.bak.时间戳`
- 自动把 `bbr` 别名指向本地副本，可选择立即以新版本重启
- 任一步失败都不会破坏现有脚本

## 常见问题

**Q: 安装后运行 `bbr` 提示找不到命令？**

A: 请执行 `source ~/.bashrc` 重新加载配置，或者断开 SSH 重连即可。

**Q: 运行 `bbr` 提示 `curl: (22) The requested URL returned error: 401`？**

A: 通常是该机器旧别名或本机 `~/.curlrc` 带了异常 Authorization。请重新安装：

```bash
unalias bbr 2>/dev/null || true
unset -f bbr 2>/dev/null || true
bash <(curl -q -fsSL "https://raw.githubusercontent.com/flyto23/bbr/main/install-alias.sh?$(date +%s)")
source ~/.bashrc
```

**Q: 怎么更新脚本？**

A: 运行 `bbr`，选择 **98. 更新脚本**。也可以重新执行一键安装命令覆盖安装。

**Q: 交互提示怎么输入？**

A: 提示统一为小写，例如 `(y/n) [y]`，直接输入 `y` 或 `n` 回车即可；输入大写 `Y`/`N` 也能识别。

**Q: 我的 VPS 是 ARM64（aarch64），能装 BBR v3 吗？**

A: 目前不能，这不是脚本的限制。BBR v3 至今未合入 Linux 主线内核，必须使用打过补丁重新编译的内核，而 XanMod 官方只提供 x86-64 构建，ARM 平台没有官方方案。**但 ARM 机器请直接使用功能 3**：ARM 内核自带 BBR + fq 队列算法，功能 3 的带宽检测与缓冲区调优在 ARM 上原生可用，同样能获得明显提升。功能 1 在 ARM 上会直接提示这一点。

**Q: 开启 BBR v3 需要重启吗？**

A: 是的，首次安装内核后必须重启服务器。后续修改参数（如功能 3）通常无需重启。
